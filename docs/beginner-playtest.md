# 弈境零基础玩家试用记录

日期：2026-10-13。用于验证新手操作、规则理解、9 路对局、终局计分与手动反馈。功能及运行方法见 [项目说明](../README.md)。

## 如何使用

建议由项目所有者自行邀请 3–5 位未学过围棋的人。此文档是待执行方案，没有包含真人试用结论。可以分多次完成，不限时，不比较玩家的速度。线上试玩需要现有站点访问权限；无法访问的参与者可以使用公开仓库的本地运行方式。

用独立浏览器配置或浏览器隐私窗口开始，不清除玩家日常使用的存档。使用匿名编号 P01、P02 等；不记录姓名、邮箱、账号或设备唯一标识。

主持人只读任务，不指出按钮、落点或答案。参与者允许使用游戏里的演示、提示、词典、重试和复盘。若主持人必须解释才能继续，在记录中写为“需要外部帮助”，不能算独立完成。

课程存档目前保存完成单元和最佳成绩，未完成课会从本课第一题重开；对局和终局阶段支持恢复。退出隐私窗口前先结束当前记录，避免把隐私窗口清空误认为程序丢失存档。

## 任务顺序

1. 打开游戏，说明现在应该先做什么，找到第一次落子的位置。让玩家复述交叉点与轮流落子的意思。
2. 用现有课程学习气、棋块、打吃与提子。让玩家指一个空交叉点，说明它是否算作相邻棋块的气；记录第一次作答和使用的内置帮助。
3. 在现有禁入点与劫课程中说明一次失败的原因。让玩家根据提示重试，观察能否区分“围棋规则不允许”与“可以下，但不符合练习目标”。
4. 学习停手、死子与中国面积计分。让玩家找到实际按钮并说出操作后会发生什么，不由主持人解释。
5. 按学习路线完成剩余前置单元及两个阶段测验。允许错题重练；分别记录首次分数和再次测验结果，不用最好成绩冒充首次正确率。
6. 开始一盘 9 路对局。玩家主动查看一次陪练解释或逐手复盘，说明一个提子或打吃事件。胜负不影响完成任务。
7. 玩家自行决定何时停手，完成死子确认与最终计分。问“黑棋的分数由什么组成”“白棋为什么另有贴目”“提掉的棋子是否再额外计分”。
8. 如果遇到困难，尝试打开反馈入口，复制或下载记录，再返回原流程。检查是否知道如何回到棋盘。

在已经进入两个阶段测验时，主持人不能要求打开新手说明或其他教学辅助；这部分需要完成当前测验后再观察。规则引擎或服务异常可以中止任务，不能要求玩家用错误结果继续学习。

## 如何判断下一步改什么

- 多位玩家找不到同一个操作：先改位置、名称或行动说明，保留规则与评分。
- 能找到按钮但说不清原因：检查解释是否对应真实棋局，再改教学内容。
- 首次测验差、重练后仍无法复述：回到相应概念检查演示和练习，不仅增加提示答案。
- 主持人介入才能完成：记录介入点，修复后重新试用；不能仅以按钮可点击作为学习效果证据。
- 确认出现程序异常：用完整可复现操作交给开发者；含劫或停手时必须保留真实历史，截图只能辅助。

完成自动测试和浏览器验证后，只能报告产品行为通过。完成真人任务记录后，才可报告参与者人数、完成情况与观察到的卡点；小样本结果只用于改进这一版，不能声称所有新手都能学会。
