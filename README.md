# 弈境 · 新手围棋

面向零基础玩家的中国围棋学习游戏。用小棋盘学规则，亲手练习气、提子、眼和劫，再完成一盘 9 路人机对局。水墨山水、原创棋童与浏览器合成音乐陪你慢慢学会下棋。

[在线体验](https://yijing-go-room.noisy-lamp-7809.chatgpt.site) · [新手试用记录](docs/beginner-playtest.md) · [开源参考](docs/open-source-references.md) · [参与开发](CONTRIBUTING.md) · [素材来源](ASSETS.md)

在线站点目前按站点所有者设置的访问名单开放。未获访问权限时，可以下载源码在本地运行。

## 功能

- 新手学堂：5 路规则、7 路战术、9 路实战，24 个学习单元；按顺序解锁，阶段测验达到 80 分后进入下一阶段。
- 教学任务：棋盘演示、逐级提示、错误解释、重试和悔棋。“停一手”等行动直接出现在任务卡中。
- 操作引导：可关闭、复看的新手说明；手机任务紧邻棋盘，讲解与提示可展开。错误反馈区分规则拒绝和未达到练习目标，预览不算测验答案。
- 术语词典：32 个术语的白话解释、专业定义、容易混淆的地方、演示和即时练习。
- 学习辅助：气数、打吃和坐标等独立开关；测验关闭答案辅助。
- 专项练习：按主题练习已解锁题目，或重练测验错题；提示与重试不改变原有课程成绩。
- 成组练习：最多 5 题一组，手动进入下一题；查看本轮小结，再练需巩固题或继续下一组。
- 确认落子：可独立开启，先预览落点再确认，减少触屏误操作；设置随存档保存。
- 逐手复盘：每一步查看实际提子、气数、打吃或停手说明，点击相关术语继续学习；可跳转精选事件，退出后回到原棋局或终局步骤。
- 人机对局：9 / 13 / 19 路，三种启发式电脑难度，中国面积计分与终局死子确认。
- 悔棋恢复：电脑思考时只撤回你刚下的一手；电脑已应手时撤回最近一回合，恢复对应的棋盘、提子数和历史。
- 回合讲解：开启落子解释后，保留玩家与电脑最近一回合的真实提子、气数和思考问题；电脑尚未回复时只显示玩家这一手。
- 毕业流程：完成前置课程后进行 9 路对局，确认死子、核对计分并确认结果；胜负不影响毕业，终局各步骤可刷新恢复。
- 终局引导：确认死子、核对计分、本局完成三步提示；直接显示活子、地、贴目及未归属空点，认输不冒充完成计分。
- 学习进度：本地保存，兼容旧版存档；术语状态和最佳测验成绩保留。
- 断点续学：普通课程保留当前题目和已展开提示，刷新后可继续；进入对局后仍可主动返回上次课程。
- 学习备份：手动下载课程、测验成绩、术语、毕业和续学记录；选择备份文件预览后确认替换，保留本机棋局及设置。
- 对局音乐：原创流行氛围、纯音乐，可暂停和调节音量；“在线选歌”打开外部网站。
- 手动反馈：选择困难类型、填写最多 600 字说明，可复制或下载记录；自行打开 GitHub 问题模板提交，不自动上传。

## 本地运行

需要 Node.js **22.13 或更新版本**及 npm，支持 Windows、macOS、Linux。

```sh
npm ci
npm run dev
```

访问终端显示的地址，默认 `http://localhost:5173`。不需要登录、数据库或 AI API 密钥。学习记录保存在当前浏览器 localStorage 中，清理浏览器数据会清除进度。

普通课程保存一个续学位置：当前题目、已经完成的实际操作与提示级别。刷新后可继续，或从对局点击“继续学堂”返回；学习路线选择同一课也会继续，使用“重学本课”可从头开始。开始另一普通课程会替换该位置，完成课程后清除它。

专项练习可以自由选题，也可开始一组最多 5 题的训练。成功后手动进入下一题，或提前结束查看本轮小结；小结区分独立首答完成、练习后完成和未完成，提示与重试不会被清零冒充独立完成。可以再练需巩固题，或继续当前主题的下一组。

本轮小结仅在当前练习弹窗中保留，返回选题、关闭或刷新后不恢复，不进入学习备份。它不是正式测验成绩或永久掌握程度；成组练习不改变课程分数、术语状态和原测验错题记录。需要更新测验错题记录时，仍应完成原有阶段测验。

未完成测验仍从本单元第一题重新开始；测验成绩与解锁规则保持原样。未确认的落子预览、待确认死子、错误反馈和弹窗不保存。课程内容更新或续学数据无效时舍弃续学位置，其他有效对局和成绩保留。

已完成单元、最佳成绩、对局和终局阶段可以恢复。记录只在当前浏览器保存，不自动上传或跨设备同步。浏览器拒绝存储时仍可在当前页面下棋和调整设置，但刷新后不能保证恢复本次进度。

“备份学习进度”可下载学习记录 JSON。换浏览器或设备时，自行传送文件，再选择文件、检查摘要并确认替换。恢复会替换学习记录，不合并成更高成绩；当前棋局、终局、音乐和操作设置保持原样。这是学习备份，不是完整棋局、棋谱或反馈文件，不包含未完成测验答案，也没有云同步。

只接受本游戏学习备份格式，文件上限 1 MiB；有错误的文件不会覆盖现有记录。课程已更新或续学位置无效时会在预览中提示，其他有效学习记录仍可恢复。浏览器拒绝存储时可下载当前内存进度，恢复写入失败则不替换原记录。电脑回合、未完成测验、待确认落子和逐手复盘期间不能操作备份；终局需沿用原流程确认后返回学堂。备份中的成绩是本地记录，不是官方学习证书。

```sh
npm test
npm run typecheck
npm run lint
npm run build
npm start
```

`npm start` 在本地运行构建后的 Cloudflare Worker，使用其打印的地址。项目含 Sites 配置，部署为自己的站点时应使用自己的项目配置。

## 规则与限制

采用中国面积计分：活棋数量与围住的空点相加，提子数量不重复计入得分；界面以白贴 7.5 目等价显示。双方连续停一手后进入终局，先确认死子，再确认最终结果。

停一手表示把回合交给对方，棋盘没有下满也可停手。本入门电脑会跟随玩家停手，这是本游戏的电脑行为，不是对手必须停手的围棋规则。

引擎处理占点、提子、禁入点、历史重复局面和停一手。规则演示通过引擎回放，不能只凭静态布局描述劫或终局。5 / 7 路用于教学，对局提供 9 / 13 / 19 路。

这是入门产品，不能代替赛事裁判。三档本地 AI 没有正式级位校准，死活确认需要用户参与；复杂争议局面、职业棋谱分析和真人联网不在当前能力范围。KataGo 是后续候选，目前没有接入。

复盘按实际动作通过规则引擎顺序回放校验，为当前一步提供规则事实和思考问题，并精选最多三个事件。开局不编造落子；记录无法验证时，该步及后续不生成讲解或精选，仍可只读查看、返回原流程。翻页不改变真实棋局、成绩或课程续学位置，也不自动播报或上传；主动查看词典沿用既有术语学习记录。

复盘没有引擎胜率、最佳着法判断、变化树或 SGF 导入。气数和提子说明用于理解发生了什么，不能据此认定这一手是最佳选择。

反馈记录只包含玩家填写的说明、困难类型，以及打开时的模式、棋盘大小和普通课程行动；正在作答的测验只记模式与棋盘大小。不附完整存档、棋谱、账号或成绩，请不要在说明中填写个人信息。

本轮自动测试和浏览器检查验证产品行为，尚未收集真人试用结果，不能据此保证零基础玩家已经能独立学会围棋。[试用协议](docs/beginner-playtest.md)提供不限时、可分多次完成的任务和匿名观察表。

